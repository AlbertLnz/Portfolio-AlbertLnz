## Introduction

**Warp** is a modern terminal with a **GUI** that leverages **AI** to generate custom prompts for you, enhancing productivity and efficiency.

## Installation of Warp

To install Warp, visit the [Warp website](https://www.warp.dev/) and download the latest version for your operating system.

## Creating Your First Theme in Warp

### Through the Warp Interface

1. Open the **Warp terminal**.
2. Click on your **profile** and navigate to the **Settings** tab.
3. Go to the **Appearance** section.
4. Under **Current Theme**, select an existing theme or create a new one.
5. Click the **`+` button** to create a custom theme using an image.

### Through Files (Linux)

1. Navigate to the Warp themes directory:

```bash
~/.warp/themes/
```

2. Add your custom image to this directory.
