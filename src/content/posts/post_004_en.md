## Introduction

Here’s a list of my favorite JavaScript-related VSCode extensions that I use regularly.

## Extensions That I Use and Recommend 🫰

- **_[Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)_** – Formats your code automatically according to Prettier rules, ensuring consistency and readability.

- **_[ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)_** – Helps you identify and fix issues in your JavaScript code with linting rules.

- **_[Error Lens](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens)_** – Highlights errors and warnings directly in your editor for better visibility.

- **_[Console Ninja](https://marketplace.visualstudio.com/items?itemName=WallabyJs.console-ninja)_** – Displays runtime errors directly in VSCode, making debugging more efficient.

- **_[Template String Converter](https://marketplace.visualstudio.com/items?itemName=meganrogge.template-string-converter)_** – Converts regular strings to template literals and vice versa.

- **_[Live Preview](https://marketplace.visualstudio.com/items?itemName=ms-vscode.live-server)_** – A Microsoft-supported extension that provides real-time website previews.

- **_[Svg Preview In Code](https://marketplace.visualstudio.com/items?itemName=lzp.svg-preview-in-code)_** – Enables real-time SVG file previews within VSCode.

- **_[Image preview](https://marketplace.visualstudio.com/items?itemName=kisstkondoros.vscode-gutter-preview)_** – Allows you to preview images directly inside your code editor.

- **_[Rest Client](https://marketplace.visualstudio.com/items?itemName=humao.rest-client)_** – Lets you send HTTP requests and view responses directly in VSCode.

- **_[Version Lens](https://marketplace.visualstudio.com/items?itemName=pflannery.vscode-versionlens)_** – Displays the latest available versions of dependencies in your project files.

## Extensions to Avoid 🙅

- **_[GitLens](https://marketplace.visualstudio.com/items?itemName=eamodio.gitlens)_** is a VSCode extension that helps you visualize code changes.
  _Reason:_ It's a powerful extension but can be resource-heavy. Plus, VSCode now includes built-in Git features like CodeLens.

- **_[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)_** is a VSCode extension that allows you to preview your website in real time.
  _Reason:_ Despite having over 50M downloads, Microsoft offers an official alternative (_Live Preview_), making this extension redundant.

- **_[Auto Rename Tag](https://marketplace.visualstudio.com/items?itemName=formulahendry.auto-rename-tag)_** is a VSCode extension that automatically renames HTML tags.
  _Reason:_ Previously one of the most popular extensions (+20M downloads), but now VSCode includes this feature natively (_Auto Closing Tags_).
