## Introducción

Aquí hay una lista de mis extensiones favoritas relacionadas con JavaScript que utilizo regularmente.

## Extensiones que utilizo y recomiendo 🫰

- **_[Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)_** – Formatea tu código automáticamente de acuerdo con las reglas de Prettier, asegurando la coherencia y la legibilidad.

- **_[ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)_** – Te ayuda a identificar y corregir problemas en tu código JavaScript con reglas de linting.

- **_[Error Lens](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens)_** – Resalta errores y advertencias directamente en tu editor para una mejor visibilidad.

- **_[Console Ninja](https://marketplace.visualstudio.com/items?itemName=WallabyJs.console-ninja)_** – Muestra errores de tiempo de ejecución directamente en VSCode, haciendo que el depuración sea más eficiente.

- **_[Template String Converter](https://marketplace.visualstudio.com/items?itemName=meganrogge.template-string-converter)_** – Convierte cadenas regulares a cadenas de plantilla y viceversa.

- **_[Live Preview](https://marketplace.visualstudio.com/items?itemName=ms-vscode.live-server)_** – Un complemento de Microsoft compatible que proporciona vistas previas en tiempo real de sitios web.

- **_[Svg Preview In Code](https://marketplace.visualstudio.com/items?itemName=lzp.svg-preview-in-code)_** – Permite ver imágenes SVG en tiempo real dentro de VSCode.

- **_[Image preview](https://marketplace.visualstudio.com/items?itemName=kisstkondoros.vscode-gutter-preview)_** – Te permite ver imágenes directamente dentro de tu editor de código.

- **_[Rest Client](https://marketplace.visualstudio.com/items?itemName=humao.rest-client)_** – Te permite enviar solicitudes HTTP y ver respuestas directamente en VSCode.

- **_[Version Lens](https://marketplace.visualstudio.com/items?itemName=pflannery.vscode-versionlens)_** – Muestra las últimas versiones disponibles de las dependencias en tus archivos de proyecto.

## Extensiones a evitar 🙅

- **_[GitLens](https://marketplace.visualstudio.com/items?itemName=eamodio.gitlens)_** es un complemento de VSCode que te ayuda a visualizar los cambios de código.
  _Razón:_ Es un poderoso complemento pero puede ser pesado en recursos. Además, VSCode ahora incluye las características de Git como CodeLens.

- **_[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)_** es un complemento de VSCode que te permite ver tu sitio web en tiempo real.
  _Razón:_ Aunque tenga más de 50 millones de descargas, Microsoft ofrece una alternativa oficial (_Live Preview_), lo que hace que esta extensión sea redundante.

- **_[Auto Rename Tag](https://marketplace.visualstudio.com/items?itemName=formulahendry.auto-rename-tag)_** es un complemento de VSCode que te permite renombrar automáticamente las etiquetas HTML.
  _Razón:_ Anteriormente una de las extensiones más populares (+20 millones de descargas), pero ahora VSCode incluye esta característica nativamente (_Auto Closing Tags_).
