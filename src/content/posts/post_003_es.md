## Introducción

**Warp** es un terminal moderna con una **GUI** que aprovecha **IA** para generar preguntas personalizadas para ti, mejorando la productividad y la eficiencia.

## Instalación de Warp

Para instalar Warp, visita el [sitio web de Warp](https://www.warp.dev/) y descarga la última versión para tu sistema operativo.

## Creando tu primer tema en Warp

### A través de la interfaz de Warp

1. Abre el **terminal de Warp**.
2. Haz clic en tu **perfil** y navega a la pestaña **Configuración**.
3. Vaya a la sección **Apariencia**.
4. Bajo **Tema actual**, selecciona un tema existente o crea uno nuevo.
5. Haz clic en el botón **`+`** para crear un tema personalizado utilizando una imagen.

### A través de archivos (Linux)

1. Navega al directorio de temas de Warp:

```bash
~/.warp/themes/
```

2. Agrega tu imagen personalizada a este directorio.
